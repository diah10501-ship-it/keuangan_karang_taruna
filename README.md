# Project Keuangan Karang Taruna

Aplikasi web manajemen keuangan Karang Taruna berbasis PHP dan MySQL.

## Fitur Utama
- Manajemen Anggota
- Pencatatan Kas / Bendahara
- Laporan Keuangan
- Kegiatan Sosial

## Cara Penggunaan
1. Import file database `.sql` di folder project ke phpMyAdmin.
2. Sesuaikan konfigurasi database pada folder `config/`.
3. Jalankan project melalui server lokal (Laragon / XAMPP).
